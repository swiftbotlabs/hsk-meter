2. Try to get paid data without paying

Ask for a price, then send the quote back changed. The endpoint has to refuse each one before it serves anything.

  1. Ask for the price of an address profile. Your browser makes up a throwaway payer address; the endpoint binds the quote to it.

  2. Send the quote back as if you had paid. Every change below should be refused.

Why it holds: the quote token is a keyed MAC over the endpoint, the payer, the exact request and the price, so any change makes it unknown to the server. The requestId is derived from the token and starts with the payer address, and the endpoint serves only after it reads that requestId as paid on the contract (getPayment), then serves it once.
